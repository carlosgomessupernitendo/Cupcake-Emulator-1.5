# Cupcake Emulator 1.5

An Android 1.5 Cupcake emulator with modern adaptations.

## About

Cupcake Emulator 1.5 is an open-source project aiming to run the original Android 1.5 operating system inside a modern Android application.

## Main features

- Original Android 1.5 Cupcake system
- Modern hardware adaptations
- Classic Android applications
- Independent Android Market
- Application compatibility checking
- Persistent virtual storage
- Touchscreen support
- Audio and network adaptations

## Android Market

The project will include an independent application catalog inspired by the original Android Market from 2009.

Applications will be selected according to their compatibility with Android 1.5 (API 3).

## Development

The project is developed using GitHub's web interface and cloud build services.

No Termux installation is required.
